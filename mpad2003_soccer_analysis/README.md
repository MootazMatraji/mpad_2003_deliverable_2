# MPAD 2003 — Soccer Field Lighting Analysis

This project contains the draft report and the student's actual Google Sheets screenshots. The screenshots of raw, cleaned and pivot data are present, along with the user-exported Google Sheets chart PNG. The Delivering Data section includes the user-supplied screenshot of Ottawa’s 2026 sports-field rental table.

## Open the report

Open `report.md` in Visual Studio Code. It combines the individual Markdown sections, and uses relative image links to the `images/` directory. The numbered `.md` files mirror the sections in `report.md`.
